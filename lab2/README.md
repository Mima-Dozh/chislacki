## Задание 2.1

Уравнение: `sin(x) - x² + 1 = 0`. График выделяет отрезок `[1, 1.5]`,
начальное приближение — `1.5`. На положительной полуоси корень единственный:
на `[0, 1]` функция положительна, при `x >= 1` строго убывает.

Для простой итерации `phi(x) = sqrt(1 + sin(x))`; на выбранном отрезке
`|phi'| <= q ≈ 0.1991`, и phi отображает отрезок в себя.
Оценка ошибки: `q/(1-q) * |x_k - x_(k-1)|`.
Ньютон использует аналитическую производную `cos(x) - 2*x`.
Его ошибка оценивается через `|f(x)| / m`, где `m = 2 - cos(1)` — нижняя
граница модуля производной на отрезке.

## Задание 2.2

При `a = 4` система имеет вид:

```text
x²/16 + y²/4 = 1
4*y - exp(x) - x = 0
```

Графически выбрана область `[1.6, 1.8] × [1.75, 1.85]` и начальная точка
`(1.7, 1.8)`. Положительные ветви эллипса и экспоненциальной кривой
соответственно убывают и возрастают, поэтому положительное пересечение единственно.

Простая итерация одновременно обновляет компоненты:
`phi = (log(4*y - x), 2*sqrt(1 - x²/16))`.
Выбранная область отображается в себя, норма Якобиана phi ограничена
`q = 25/26 < 1`. Оценка ошибки использует норму максимума и множитель `q/(1-q)`.
Ньютон решает линейную систему `J*delta = -F` через `numpy.linalg.solve`.
Для его приближений в этой области используется оценка `||phi(x)-x||∞/(1-q)`.
При смене уравнений или области нужно пересчитать границы производных и q.

## Сходимость

При `epsilon = 1e-6`:

|---|---|---|---|

Простая итерация имеет линейную сходимость, Ньютон около простого корня —
квадратичную. Графики показывают верхние оценки ошибки, а не точную ошибку;
оценки могут быть консервативными и меняться немонотонно.
